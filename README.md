# AI献立プランナー - siasatteken

OpenAI APIを使ってユーザーの食べたいものを取り入れつつ、栄養バランスを最適化した献立を提案するWebアプリケーションです。

## 機能

- **献立作成**: ユーザーの希望を入力すると、AIが栄養バランスを考慮した献立を提案
- **画像生成**: DALL-E 3を使って献立のイメージ画像を自動生成
- **対話型調整**: 「朝食を少なくしたい」「これが嫌い」などの要望に応じて献立を修正
- **ユーザー設定**: アレルギー、苦手な食材、ベジタリアン、ヴィーガン、グルテンフリーなどの食事制限に対応
- **履歴管理**: 過去の献立を保存・参照できる
- **お気に入り**: 気に入った献立をお気に入りとして保存
- **カレンダー**: 日別・週別・月別の栄養摂取量を確認できる

## セットアップ

### 必要なもの

- Node.js 18以上
- OpenAI APIキー（[OpenAI Platform](https://platform.openai.com/)で取得）

### インストール

1. リポジトリをクローン

```bash
git clone https://github.com/Tomboat7/siasatteken.git
cd siasatteken
```

2. 依存関係をインストール

```bash
npm install
```

3. 環境変数を設定

`.env.example`をコピーして`.env`ファイルを作成し、OpenAI APIキーを設定してください。

```bash
cp .env.example .env
```

`.env`ファイルを編集:
```
OPENAI_API_KEY=your_openai_api_key_here
```

**重要**: `.env`ファイルは`.gitignore`に含まれているため、Gitにコミットされません。

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

### 本番ビルドとデプロイ

```bash
npm run build
npm start
```

## 使い方

### 1. 献立作成

1. トップページで朝食、昼食、間食、夕食に食べたいものを入力
2. その他の要望（例: 朝は少なめに、野菜を多めに）を追加
3. 「献立を作成する」ボタンをクリック
4. AIが栄養バランスを考慮した献立を提案

### 2. 献立の調整

- 作成された献立に対して、チャット形式で要望を伝えて修正可能
- 例: 「朝食を軽くしたい」「魚を避けたい」など自由に入力

### 3. 画像生成

- 各料理の「画像を生成」ボタンで、AI生成の料理画像を追加
- DALL-E 3により美味しそうな料理写真を自動生成

### 4. ユーザー設定

1. ナビゲーションの「設定」をクリック
2. 食事制限を設定
   - ベジタリアン、ヴィーガン、グルテンフリーのチェックボックス
3. アレルギー食材を登録
4. 苦手な食材を登録
5. 「NG食材設定を無視する」で一時的に制限を解除可能
6. 「設定を保存」をクリック

### 5. 履歴とお気に入り

1. 献立作成後、「履歴に保存」ボタンで保存
2. 「お気に入りに追加」で特に気に入った献立をブックマーク
3. ナビゲーションの「履歴」から過去の献立を確認
4. 「履歴」タブと「お気に入り」タブで切り替え

### 6. カレンダー・栄養記録

1. ナビゲーションの「カレンダー」をクリック
2. 日付を選択して、その日の栄養価を確認
3. 表示期間を「1日」「1週間」「1ヶ月」から選択
4. 総カロリー、タンパク質、炭水化物、脂質、食物繊維、塩分を確認

## 技術スタック

- **フレームワーク**: Next.js 16 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS v3
- **AI**: OpenAI API
  - GPT-4o: 献立生成・栄養計算
  - DALL-E 3: 料理画像生成
- **ストレージ**: localStorage (クライアントサイド)

## 注意事項

- **API使用料**: OpenAI APIの使用には料金がかかります。利用前に[OpenAIの料金体系](https://openai.com/pricing)を確認してください。
- **データ保存**: 現在はブラウザのlocalStorageにデータを保存しています。ブラウザのキャッシュをクリアするとデータが失われます。
- **セキュリティ**: APIキーは`.env`ファイルに保存し、絶対にGitにコミットしないでください。

## トラブルシューティング

### ビルドエラーが発生する

```bash
# node_modulesとビルドキャッシュをクリア
rm -rf node_modules .next
npm install
npm run build
```

### APIエラーが発生する

1. `.env`ファイルにOpenAI APIキーが正しく設定されているか確認
2. APIキーが有効で、使用制限に達していないか確認
3. インターネット接続を確認
