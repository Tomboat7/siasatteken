# AI献立プランナー - siasatteken

OpenAI APIを使ってユーザーの食べたいものを取り入れつつ、栄養バランスを最適化した献立を提案するWebアプリケーションです。

## 機能

- **献立作成**: ユーザーの希望を入力すると、AIが栄養バランスを考慮した献立を提案
- **画像生成**: DALL-E 3を使って献立のイメージ画像を自動生成
- **対話型調整**: 「朝食を少なくしたい」「これが嫌い」などの要望に応じて献立を修正
- **ユーザー設定**: アレルギー、苦手な食材、ベジタリアン、ヴィーガン、グルテンフリーなどの食事制限に対応
- **履歴管理**: 過去の献立を保存・参照できる
- **お気に入り**: 気に入った献立をお気に入りとして保存
- **カレンダー**: 日別・週別・月別の栄養摂取量を確認できる

## セットアップ

### 必要なもの

- Node.js 18以上
- OpenAI APIキー

### インストール

1. リポジトリをクローン

```bash
git clone https://github.com/Tomboat7/siasatteken.git
cd siasatteken
```

2. 依存関係をインストール

```bash
npm install
```

3. 環境変数を設定

`.env.example`をコピーして`.env`ファイルを作成し、OpenAI APIキーを設定してください。

```bash
cp .env.example .env
```

`.env`ファイルを編集:
```
OPENAI_API_KEY=your_openai_api_key_here
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

### ビルド

```bash
npm run build
npm start
```

## 使い方

1. **献立作成**
   - トップページで朝食、昼食、間食、夕食に食べたいものを入力
   - その他の要望（例: 朝は少なめに、野菜を多めに）を追加
   - 「献立を作成する」ボタンをクリック

2. **献立の調整**
   - 作成された献立に対して、チャットで要望を伝えて修正
   - 「朝食を軽くしたい」「魚を避けたい」など自由に入力

3. **画像生成**
   - 各料理の「画像を生成」ボタンで、AI生成の料理画像を追加

4. **ユーザー設定**
   - ナビゲーションの「設定」から食事制限を設定
   - アレルギー食材や苦手な食材を登録
   - ベジタリアン、ヴィーガン、グルテンフリーなどのオプションを選択

5. **履歴とお気に入り**
   - 献立を履歴に保存
   - 気に入った献立をお気に入りに追加
   - 「履歴」ページで過去の献立を確認

6. **カレンダー**
   - 日別・週別・月別の栄養摂取量を確認
   - 過去の献立を振り返る

## 技術スタック

- **フレームワーク**: Next.js 16 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **AI**: OpenAI API (GPT-4o, DALL-E 3)
